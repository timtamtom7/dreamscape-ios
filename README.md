# Dreamscape

A dream journal that turns fleeting dreams into a constellation of meaning. Apple Intelligence finds the recurring threads — symbols, people, places — and maps the subconscious landscape over time.

## Concept

- Voice or text entry on waking
- Recurring symbol, person, and place detection
- A visual Dream Map that builds over time
- Community sharing
- iCloud sync

## Targets

- iOS
- DreamscapeMac
- DreamscapeWidgets

## Stack

- SwiftUI
- Apple Intelligence
- CloudKit
- XcodeGen (`project.yml`)

## Structure

Key types: `AppleIntelligenceService`, `AuroraDreamCard`, `CloudSyncService`, `CommunityService`/`CommunityView`.

Version 1.0.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
